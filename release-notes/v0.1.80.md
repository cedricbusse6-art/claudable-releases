# Claudable Launcher v0.1.80

fix: eliminate black screen on Settings navigation (v0.1.80)

Replace always-mounted RgbSketchPad (CSS-hidden) with conditional mount.
Layout now renders {secretMode && pathname === '/' && <RgbSketchPad />}
so the canvas DOM node is fully removed on navigation away from Home.

The old approach (display:none + visibility:hidden + opacity:0) could not
beat the Electron GPU compositor race — the composited canvas layer
persisted for at least one frame after React's style commit, causing a
black screen on every route transition while secretMode was active.

Changes:
- Layout.tsx: conditional mount instead of active prop
- RgbSketchPad.tsx: remove active prop, simplify canvas styles,
  useEffect dep array [] (runs once on mount, cleans up on unmount)
