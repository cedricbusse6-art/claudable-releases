# Claudable Launcher v2.0.21

feat(v2.0.21): subnet discovery for the Pi, stable mDNS endpoint

The wizard had a hardcoded 192.168.2.136. DHCP handed the Pi a new
address after a reboot, so the configured endpoint went stale and the
launcher reported 'not connected' even though the Pi was healthy.

- new ollama:discover IPC scans the local /24 and probes /api/tags
- wizard gets an 'Auto-discover' button listing found hosts, sorted to
  prefer a host serving qwen2.5-coder and de-prioritise localhost
- default endpoint is now raspberrypi.local (mDNS), which survives DHCP
- remote 'start Ollama' error now explains the actual remedy and no
  longer hardcodes a personal SSH username
- unreachable-host message names the endpoint and the one command to
  run on the Pi
- replaced a require() call with a proper node:os import
