# Claudable Launcher v2.0.22

fix(v2.0.22): make node registration actually work

Three independent blockers prevented any node from ever registering:

1. settings:set silently dropped the DePIN fields, so depinAutoStartNode
   never persisted and createNodeAgentFromSettings() returned null on the
   next launch. settings:get also omitted them, so the wizard toggle read
   back as 'off'. Both now pass the full settings object.
2. process.env.VITE_SUPABASE_* is not substituted by Vite in the main
   process build, so the agent saw empty credentials and bailed. Now
   injected via define (both root and the electron main inline config,
   since the plugin does not merge the root define).
3. register_node derives owner_id from auth.uid(), which is NULL with the
   anon key, and owner_id is NOT NULL -> the RPC could never succeed. The
   renderer now forwards the session JWT through node-agent:set-auth and
   the agent sends it as a Bearer header.

Also replaced the live get_node_admin_stats stub (it returned only
aggregate counters) with the real per-node rows, which is what made the
admin page render a single phantom row.
